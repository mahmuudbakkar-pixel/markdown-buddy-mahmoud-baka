## Overview

This small R project demonstrates clear documentation for a reproducible data-analysis workflow. Its deliberately limited script displays a fictional sales table. It does not calculate totals, averages or other results. The emphasis is on explaining a script, documenting dependencies and organizing a professional repository.

All example records are synthetic. No customer details, business records or private datasets are used.

## Installation

1. Install R and, optionally, RStudio.
2. Download this repository and open its root directory as your working directory.
3. To render the documentation, install the additional R packages:

```r
install.packages(c("rmarkdown", "knitr"))
```

The display script uses base R only. Rendering the R Markdown document additionally requires Pandoc; RStudio normally supplies it. Rebuilding the PDF additionally requires a LaTeX distribution with XeLaTeX. Reading the provided PDF requires neither R nor LaTeX. Installation requires an internet connection; running the display example does not.

## Example Usage

Run this command from the repository root in the R console:

```r
source("sales_display.R")
```

The script creates `sales` in the current R session and prints it to the console. It writes no files. The input values are fictional, fixed observations rather than calculated output.

| Month | Product | Units |
| --- | --- | --- |
| January | Notebook | 12 |
| February | Notebook | 15 |
| March | Notebook | 9 |

To knit the accompanying document:

```r
rmarkdown::render("sales_display.Rmd", output_format = "html_document")
```

For the printable version, run `rmarkdown::render("sales_display.Rmd", output_format = "pdf_document")`.

The expected HTML output file is `sales_display.html`. The included `sales_display.html` was generated by executing this R Markdown document with R 4.3.3, rmarkdown 2.25 and knitr 1.45.

## Troubleshooting

- **Cannot open the script:** set the working directory to the repository root.
- **Package not found:** install `rmarkdown` and `knitr` before rendering.
- **Pandoc not available:** render inside RStudio or install Pandoc separately.
- **Unexpected values:** compare the three records with the table above; do not substitute real personal data.
